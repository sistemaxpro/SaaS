# GUIA USUARIO PRINCIPIANTE - SISTEMAX

## Objetivo
Esta guia esta pensada para usuarios nuevos. Explica el flujo minimo para operar sin errores en el dia a dia.

## Flujo Diario Recomendado
1. Iniciar sesion con tu usuario.
2. Abrir `POS` desde el menu principal.
3. Seleccionar cliente (o cliente contado segun politica del negocio).
4. Agregar productos por codigo o descripcion.
5. Confirmar total, tipo de documento y medio de pago.
6. Emitir comprobante e imprimir ticket.
7. Si necesitas reimpresion, usar `Mis Ventas`.
8. Revisar movimiento en `Caja`.

## Modulos Basicos
- `POS`: venta rapida, emision y cobro.
- `Mis Ventas`: consulta, filtros y reimpresion.
- `Caja`: control de entradas/salidas y resumen del dia.
- `Clientes`: datos, busqueda y saldos.
- `Productos`: alta, stock y precios.
- `Compras`: registro de facturas de proveedores.
- `Facturas`: gestion de documentos y seguimiento.

## Consultas Rapidas para Vcorta
Usa preguntas cortas y directas:
- `Cuanto vendimos hoy`
- `Top clientes con deuda`
- `Listar tablas`
- `Columnas de factura_ventas`
- `Abrir POS`
- `Abrir caja`
- `Abrir clientes`

## Buenas Practicas
- Confirmar cliente y monto antes de emitir.
- Verificar medio de pago antes de confirmar.
- Reimprimir solo desde `Mis Ventas` para trazabilidad.
- Revisar `Caja` al cierre para cuadrar el dia.

## Errores Comunes
- Cobro con medio de pago equivocado.
- Emitir documento incorrecto (Control vs FE).
- No revisar saldo pendiente del cliente.
- Omitir control de caja al cierre.

## Soporte Operativo
Si tenes dudas, pedi a Vcorta:
- `Soy principiante, guiame para vender`
- `Guiame para cerrar caja`
- `Explicame como reimprimir una venta`
